Guide d'utilisation
===================

Navigation du site
------------------

La page d'accueil permet d'accéder aux locations et aux profils disponibles.

Consulter une location
----------------------

Depuis la liste des locations, l'utilisateur peut sélectionner une location
afin de consulter ses informations et son adresse.

Consulter un profil
-------------------

Depuis la liste des profils, l'utilisateur peut sélectionner un profil afin
de consulter ses informations.

Administration
--------------

L'interface d'administration Django est accessible à l'adresse :

``http://127.0.0.1:8000/admin/``

Pour l'environnement de développement fourni avec le projet, utilisez :

- **Utilisateur :** ``admin``
- **Mot de passe :** ``Abc1234!``

.. warning::

    Ces identifiants sont fournis uniquement pour l'environnement de
    développement et de démonstration. Ils ne doivent pas être utilisés
    en production. En production, créez un compte administrateur avec
    un mot de passe sécurisé.
