Orange County Lettings
======================

Bienvenue dans la documentation technique de Orange County Lettings.

Description du projet
---------------------

Orange County Lettings est une application web développée avec Django
permettant de consulter des annonces de locations immobilières et les
profils associés.

L'application permet notamment :

- de consulter les locations disponibles ;
- de consulter le détail d'une location ;
- de consulter les profils des utilisateurs ;
- d'administrer les données via l'interface d'administration Django.

Cette documentation présente les aspects techniques de l'application ainsi
que les procédures nécessaires à son installation, son utilisation, ses
tests et son déploiement.
